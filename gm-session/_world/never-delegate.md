# NEVER DELEGATE

> The GM-only list. The agent is aware this file exists and never generates its contents,
> under any mode. This is a hard line, mirrored as a code-level hard ban, it does not
> rely on the agent reading this file to be enforced.

Everything below is the GM's alone:

- Villain identities, plans, and motivations.
- Story reveals and secrets becoming known.
- Any consequence that lands on a player character.
- Table-safety calls (lines, veils, X-card moments).
- The true reason behind any public mystery (e.g. *why* the road is closing).

If a moment touches any of these, the agent produces nothing and notes why. The GM takes
it from there. That is the system working.
