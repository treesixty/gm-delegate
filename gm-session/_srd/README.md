# _srd, your rules corpus

> Catalog. Drop your own CC-BY-4.0 SRD 5.1 / 5.2.1 rules text here, attributed. The
> rules-lookup stage reads ONLY from this folder.
>
> This is NOT the GM's paid Foundry compendium. Reading that wholesale at runtime is a
> hard ban (spec §1.1, §1.4). A specific licensed statblock is fetched by explicit ID
> through the tool surface, GM-initiated, never swept from here.
>
> Attribution required by CC-BY-4.0. Keep the license notice with the text.
